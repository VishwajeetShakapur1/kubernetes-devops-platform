# SLI / SLO

Example availability SLI:

```text
successful requests / total requests
```

Example target:

```text
99.5% availability over 30 days
```

The repository also keeps a simple error-budget calculation:

```text
error budget = 1 - SLO
             = 0.5%
```

These values are examples for the project and are not claims about production systems.
